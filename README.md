# 📂 Centralizador de CVs y Gestión de Postulantes

Este proyecto busca **centralizar en un solo lugar** la recepción de currículums que actualmente llegan de forma dispersa por WhatsApp, Instagram y correo electrónico, facilitando el orden para el administrador.

## 🚀 Funcionalidades Principales
* **Usuario:** Puede postularse manualmente a una oferta o dejar su CV cargado en la base de datos.
* **Administrador:** Panel para visualizar y gestionar todos los postulantes de forma organizada.
* **Extras:** Opción de asistencia para armar el CV vía WhatsApp y sistema de notificaciones al mail.

## 🛠️ Tecnologías
* **Frontend:** React + Vite
* **Backend:** Django + Django REST Framework (API)
* **Base de datos:** SQLite

## 📂 Estructura del Proyecto
* `/frontend`: Aplicación cliente en React.
* `/backend`: API construida con Django.
* `/docs`: Documentación y recursos del proyecto.
