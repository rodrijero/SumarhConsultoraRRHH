# Portal de Empleos - Proyecto Integrador 2026

## Descripción
Nuestra plataforma facilita la conexión entre candidatos y empresas. Los usuarios pueden postularse a diversas vacantes y cargar sus CVs de forma centralizada. Por otro lado, la aplicación ofrece un panel de administración donde se pueden gestionar las ofertas laborales y revisar las postulaciones recibidas en un solo lugar.

## Tecnologías
* **Frontend:** React.js para una interfaz dinámica.
* **Backend:** Node.js para la gestión de datos.
* **Control de Versiones:** Git y GitHub.
* **Documentación:** Markdown.

## Secciones Principales
1. **Portal del Candidato:** Visualización de trabajos y carga de CV.
2. **Panel de Administración:** Carga de nuevas vacantes y gestión de postulantes.

## Setup e Instalación
1. Clonar el repositorio.
2. Ejecutar `npm install` en las carpetas correspondientes.
3. Iniciar el entorno de desarrollo con `npm start`.
